# legacy/

Перша версія бота: три окремі скрипти, які самі знімали екран, самі тиснули клавіші
і читали `legacy/settings.json`. Робоча, але не масштабується на кілька вікон і на веб.

Замінена модульною архітектурою в `app/` (див. README.md у корені). Лишена як довідка
і як запасний варіант — запускається окремо:

```bash
.venv\Scripts\python legacy\target_monitor.py --dry
```

Нічого нового сюди не додавати. Уся калібровка тепер живе в `config/windows.json`.
